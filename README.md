# Treecapitator

Adds the **Treecapitator**, an axe that looks like the stone axe but fells any tree **and breaks its stump** in a single swing, dropping all its wood straight away instead of a log. Leftover stumps also break in one swing.

Use the **secondary attack** to fell every tree and break every stump within 20m: the logs fall all around you. The radius can be changed in the config file `BrugherheimFolks.Treecapitator.cfg`.

Craft it at the workbench with 4 Wood and 2 Stone.

## Installation

Install with r2modman / Thunderstore Mod Manager, or extract the Nexus Mods zip into your Valheim folder.
Requires BepInExPack Valheim and Jötunn.

## Multiplayer

Install on every client **and** the server. Jötunn enforces that everyone has the same version.
